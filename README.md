# Нейрорадар

Агрегатор новостей о мире искусственного интеллекта: нейросети, вайбкодинг,
ИИ-агенты, платформы, дизайн, вакансии и заказы на фриланс.

**Сайт:** https://dmserge77.github.io/ai-news/

## Что это

Статический сайт, который сам себя собирает шесть раз в день. Никакого сервера,
никакой базы данных, никаких внешних библиотек — только стандартная библиотека
Python и GitHub Actions.

Сборщик читает 36 RSS-лент и два кадровых источника, отбирает материалы про ИИ,
раскладывает их по восьми рубрикам и собирает готовые страницы в `docs/`.

## Как это работает

```
Источники  ->  Сбор  ->  Фильтр  ->  Дедупликация  ->  data/  ->  docs/  ->  Pages
                (RSS)   (правила)     (3 проверки)     (архив)   (сайт)
```

1. **Сбор** — `news/fetch.py` читает ленты и приводит записи к одному виду.
2. **Фильтр** — `news/filters.py` оставляет только то, что про ИИ.
   Что не прошло, но похоже на правду, уезжает в «Солянку», а не удаляется.
3. **Дедупликация** — `news/dedup.py` сверяет ссылку и «источник + заголовок + дата».
4. **Архив** — `data/*.json`, 90 дней истории, лежит в git.
5. **Сайт** — `news/render.py` собирает `docs/`, откуда всё публикуется на Pages.

## Запуск

```bash
python collect.py                                    # собрать новости и сайт
python -m unittest discover -s tests -t .            # прогнать тесты
python snapshot.py save --note "повод"               # снять снимок архива
python snapshot.py restore _snapshots/<файл>.json.gz # восстановить из снимка
python check_jobs.py                                 # перепроверить вакансии в архиве
python check_jobs.py --apply                         # ...и убрать неподходящие
python why.py рачки                                  # почему этой новости нет на сайте
python why.py                                        # сводка по отказам фильтров
GITHUB_TOKEN=<токен> python watchdog.py              # проверить сторожа
```

Внешних зависимостей нет — ставить ничего не нужно. Достаточно Python 3.11+.

## Рубрики

| Ключ | Название | Что попадает |
|---|---|---|
| `ai` | Нейросети | модели, компании, исследования |
| `vibe` | Вайбкодинг | генерация кода, ИИ-редакторы, no-code |
| `agent` | ИИ-агенты | автономные агенты, MCP, оркестрация |
| `platform` | Платформы | API, облака, релизы, инфраструктура |
| `design` | Дизайн | интерфейсы, вёрстка, инструменты |
| `misc` | Солянка | всё про ИИ, что не влезло в другие рубрики |
| `jobs` | Вакансии | только удалённые, с hh.ru и Работы России |
| `orders` | Есть заказ | фриланс-заказы с FL.ru, включая сайты |

Внутри «Солянки» три подрубрики: **Разное**, **Курьёзы** и
**Не фильтрованное** — карантин для записей, которые перестали проходить фильтр.
Ничего не удаляется безвозвратно.

## Обновление

- `deploy.yml` — сборка по слотам каждые 4 часа (МСК 02, 06, 10, 14, 18, 22).
- `watchdog.yml` — каждый час проверяет свежесть сайта и перезапускает сборку,
  если слот пропущен.

Расписание GitHub Actions ненадёжно: запуски задерживаются или пропадают,
поэтому и нужен сторож.

## Устройство репозитория

| Путь | Назначение |
|---|---|
| `collect.py` | точка входа сборщика |
| `news/` | логика: источники, загрузка, фильтры, дедуп, хранилище, наблюдение, вёрстка |
| `data/` | архив новостей, 90 дней, журнал источников и журнал отказов — **в git** |
| `docs/` | готовый сайт, пересобирается при каждом запуске |
| `about/`, `_category_template.html` | ручные файлы: страница «О проекте» и шаблон рубрики |
| `tests/` | тесты на стандартном `unittest` |
| `_snapshots/` | снимки архива — вторая страховка |
| `watchdog.py`, `snapshot.py` | сторож свежести и работа со снимками |
| `check_jobs.py` | перепроверка вакансий в архиве по текущим правилам |
| `why.py` | почему новости нет на сайте: поиск в архиве и журнале отказов |

Подробности для разработки — в [AGENTS.md](AGENTS.md).
